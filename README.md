# LemonsLearningWebsite

Built and deployed a custom website by combining generative AI workflows with foundational front-end development. Leveraged AI tools to accelerate architecture and code generation while applying a strong working knowledge of HTML and CSS to hand-refine layouts, style components, and ensure responsive design

## 💡 Why HTML and CSS?

I chose to build this project using foundational HTML and CSS because specific software, frameworks, and tools constantly evolve and go out of date. However, core web standards remain timeless and reliable—mastering the fundamentals ensures the general base will always work.

This website was designed to look like ServiceNow.
